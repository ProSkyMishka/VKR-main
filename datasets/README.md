# Датасеты для экспериментов конвертации SwiftUI → React

**Всего: 1000 примеров** по 6 категориям (S1–S6).

Каждая папка соответствует сценарию проверки:

| Сценарий | Папка | Описание |
|----------|--------|----------|
| **S1** | `S1_layout/` | UI-отображение: VStack, HStack, ZStack, Text, Image, длинные цепочки модификаторов, сетки, карточки, dashboard. |
| **S2** | `S2_state_events/` | Состояния и события: @State, Button, Toggle, onAppear, формы, ограниченные счётчики, многошаговые мастера. |
| **S3** | `S3_binding/` | Привязки: @Binding, родитель–дочерний обмен, многоуровневые цепочки (до 4 уровней), вычисляемые отображения. |
| **S4** | `S4_list_foreach/` | Списки: List, ForEach, секции, identifiable, фильтрация по состоянию, выбор строки, вложенные циклы. |
| **S5** | `S5_navigation/` | Навигация: NavigationView/NavigationStack, NavigationLink, многоуровневая (до 3 уровней), composable-меню. |
| **S6** | `S6_animations/` | Анимации: opacity, scale, offset, rotation, spring, transition, цепочки модификаторов, два независимых элемента. |

## Структура сложности

В каждой категории представлены три уровня сложности:

- **L1 — минимальные**: один контейнер с 1–3 элементами
  (например, `vstack_simple`, `counter`, `nav_link`).
- **L2 — стандартные**: типичные шаблоны с несколькими модификаторами,
  переменным числом элементов, базовой интерактивностью
  (`vstack_block_*`, `card_block_*`, `counter_inc_*`, `nav_multi_*`,
  `bind_int_*`, `foreach_seq_*`).
- **L3 — усложнённые**: композиции из нескольких паттернов, многоуровневые
  цепочки и составные сценарии:
  - **S1**: `scroll_cards_*` (ScrollView из карточек), `tile_grid_*`
    (сетка 3×3 цветных плиток), `dashboard_*` (header + три метрики
    в карточках + footer-note), `header_body_*` (трёхзонный layout).
  - **S2**: `form_panel_*` (форма из текстового поля, переключателя
    и счётчика, сводка обновляется по Submit), `bounded_counter_*`
    (счётчик с зажимом в [0..max]), `wizard_steps_*` (state-машина
    с тремя экранами и Next/Back).
  - **S3**: `bind_chain4_*` (4-уровневая цепочка root→A→B→C→leaf),
    `bind_local_combo_*` (у дочернего компонента собственный @State плюс
    @Binding к родителю), `bind_compute_*` (родитель показывает
    вычисляемое выражение от двух биндингов).
  - **S4**: `filtered_list_*` (фильтрация по состоянию Toggle),
    `selectable_list_*` (выбор строки обновляет header), `nested_skip_*`
    (вложенные ForEach с условным пропуском нечётных строк).
  - **S5**: `nav_three_level_*` (Root → A → B → C с заголовками),
    `nav_list_detail_*` (List, у каждой строки своя DetailView с параметром),
    `nav_compose_*` (NavigationView, объединяющий VStack-меню и List).
  - **S6**: `anim_dual_*` (два независимо анимируемых элемента),
    `anim_chain_*` (один state управляет четырьмя модификаторами:
    opacity + scale + offset + rotation), `anim_cond_combo_*`
    (условный if/else + transition + scale через withAnimation).

## Тесты

Каждому `.swift` соответствует одноимённый `.spec.tsx`
(Vitest + React Testing Library) с детерминированной проверкой
ожидаемого поведения. Что проверяется:

| Сценарий | Проверка |
|----------|----------|
| **S1** | присутствие ожидаемых текстов/элементов в DOM |
| **S2** | значение/текст обновляется после клика по Button или переключения Toggle |
| **S3** | действие в дочернем компоненте отражается в родителе |
| **S4** | список содержит ожидаемое число и контент строк |
| **S5** | корневой экран показывает ожидаемый контент и ссылки навигации |
| **S6** | после действия по триггеру компонент остаётся валидным |

Все литералы у L2/L3 содержат уникальный токен (например,
`fp001-done q=1 f=0`, `b4007-root: 1`), что исключает пересечения
между тестами и неоднозначные совпадения текстов.

## Запуск конвертации

Одиночный пример:

```bash
node dist/cli.js datasets/S1_layout/vstack_simple.swift --out output-s1-1
```

Полный эксперимент по всем конфигурациям и категориям:

```bash
npm run build
npm run experiment
```

Опции `scripts/run-experiment.js`: `--samples N` — ограничить число
примеров, `--out <dir>` — каталог артефактов.
